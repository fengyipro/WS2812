#  操作指南

本文档面向实际使用与演示，按“按键控制”和“蓝牙数字控制”两种方式，逐项说明每个功能如何进入、如何操作、如何退出。



## 一. 控制方式总览

### 1. 按键控制总规则

KEY1：通常用于“选择/切换/下一项”

KEY2：通常用于“确认进入/返回退出”

按键消抖：200ms（中断置位标志，主循环处理）

对应代码：按键中断与状态机处理见[main.c:HAL_GPIO_EXTI_Callback/Handle_Keys](Core/Src/main.c#L256-L418)。

### 2. 蓝牙串口控制总规则

发送字符 `'0'`：在任意页面都表示“退出/返回上一层或主菜单”（全局退出键）

发送字符 `'1'..'9'`：在“当前页面”表示“第 1/2/3/… 个功能号”

对应代码：
数字接收与队列缓存见 [bluetooth.c](Core/Src/bluetooth.c#L1-L81)

数字与页面行为映射见 [main.c:Handle_Bluetooth_Commands](Core/Src/main.c#L420-L570)

### 3. 蜂鸣器反馈

每次“有效按键/蓝牙命令”触发短鸣反馈

短鸣为非阻塞软定时（约 15ms），并在 SysTick 中更新，避免 LCD 刷新导致的短鸣变长

对应代码：
非阻塞短鸣见 [buzzer.c](Core/Src/buzzer.c#L1-L37)

SysTick 中更新见 [stm32f1xx_it.c:SysTick_Handler](Core/Src/stm32f1xx_it.c#L183-L196)

## 二. 主菜单（MAIN MENU）

LCD 主界面显示三项功能：

1. Brightness
2. Voice Ctrl
3. Extended

对应 UI 绘制见 [main.c:UI_Refresh(MENU_HOME)](Core/Src/main.c#L572-L594)。

### 1. 按键操作

 KEY1：光标下移（循环选择 3 项）

 KEY2：进入当前选中的功能

### 2. 蓝牙操作 

发送 `1`：进入 Brightness

发送 `2`：进入 Voice Ctrl

发送 `3`：进入 Extended

发送 `0`：在主菜单无动作（仍停留主菜单）

对应逻辑见 [main.c:Handle_Bluetooth_Commands(MENU_HOME)](Core/Src/main.c#L482-L505)。

## 三. 主界面功能：Brightness（亮度调节）

### 1. 功能说明

初始亮度为 DARK（弱亮）

支持 3 档亮度循环：DARK → MEDIUM → BRIGHT → DARK

灯带显示为白色（R=G=B），通过改变灰度实现亮度变化

对应代码：
界面与进度条见 [main.c:UI_Refresh(MENU_BRIGHTNESS)](Core/Src/main.c#L596-L610)

按键调节与退出见 [main.c:Handle_Keys(MENU_BRIGHTNESS)](Core/Src/main.c#L290-L368)

蓝牙调节与退出见 [main.c:Handle_Bluetooth_Commands(MENU_BRIGHTNESS)](Core/Src/main.c#L507-L515)

### 2. 按键操作

KEY1：亮度档位循环切换（DARK/MEDIUM/BRIGHT）

KEY2：退出回到主菜单，并清灯（WS2812 全灭）且复位亮度档位为 DARK

### 3. 蓝牙操作

`1`：设置为 DARK

`2`：设置为 MEDIUM

`3`：设置为 BRIGHT

`0`：退出回到主菜单，并清灯且复位亮度档位


## 四. 主界面功能：Voice Ctrl（语音控制页）

该页面的 UI 主要用于显示“最近一次语音命令”，同时支持用蓝牙数字直接触发语音命令映射（1..5）。

对应 UI见 [main.c:UI_Refresh(MENU_VOICE)](Core/Src/main.c#L661-L669)。

### 1. 按键操作

 KEY1：返回主菜单（并清灯、复位亮度档位）

 KEY2：返回主菜单（并清灯、复位亮度档位）

对应逻辑见 [main.c:Handle_Keys(MENU_VOICE)](Core/Src/main.c#L327-L415)。

### 2. 蓝牙操作

 `1..5`：执行语音命令映射（等价于收到 USART2 的数字命令）

 `0`：退出回到主菜单（并清灯、复位亮度档位）

`1`：open（全白）

`2`：close（全灭）

`3`：red（全红）

`4`：blue（全蓝）

`5`：white（全白）

对应代码见 [main.c:Voice_Process_Command](Core/Src/main.c#L713-L743)。

### 语音控制
`1`：打开灯光

`2`：关闭灯光

`3`：红色模式

`4`：蓝色模式

`5`：白色模式



## 五. 主界面功能：Extended（扩展功能菜单）

菜单包含：

1. Color Mode

2. Music Mode

3. Auto Bright

4. Exit

对应 UI 见 [main.c:UI_Refresh(MENU_EXTENDED)](Core/Src/main.c#L612-L622)。

### 1. 按键操作

KEY1：光标下移（循环选择 4 项）

KEY2：进入当前选中的功能

在 Extended 内选择 “Exit” 后按 KEY2：返回主菜单，并清灯、复位亮度档位

对应逻辑见 [main.c:Handle_Keys(MENU_EXTENDED)](Core/Src/main.c#L298-L388)。

### 2. 蓝牙操作

`1`：进入 Color Mode

`2`：进入 Music Mode

 `3`：进入 Auto Bright

 `4`：Exit 返回主菜单（并清灯、复位亮度档位）

 `0`：从 Extended 直接回主菜单（并清灯、复位亮度档位）


对应逻辑见 [main.c:Handle_Bluetooth_Commands(MENU_EXTENDED)](Core/Src/main.c#L517-L541)。

## 六. 拓展模式Color Mode（颜色模式）

### 1. 功能说明

循环/选择预设颜色表（RED/GREEN/BLUE/YELLOW/PURPLE/CYAN/WHITE）

LED 整条同色显示

颜色表定义见 [main.c:color_modes](Core/Src/main.c#L74-L88)。

### 2. 按键操作

 KEY1：下一种颜色

 KEY2：返回 Extended，并清灯

对应逻辑见 [main.c:Handle_Keys(MENU_COLOR)](Core/Src/main.c#L303-L396)。

### 3. 蓝牙操作

`1..7`：直接选择第 1..7 个颜色（对应 color_modes 下标 0..6）

`0`：返回 Extended，并清灯

对应逻辑见 [main.c:Handle_Bluetooth_Commands(MENU_COLOR)](Core/Src/main.c#L543-L553)。

## 七. Music Mode（音乐律动）

### 1. 功能说明

进入后先进行环境噪声校准（约 5 秒），LCD 显示校准进度/阈值

校准完成后：根据麦克风强度自适应估计噪声底噪与阈值，实现“有音乐就更亮/更跳动、没音乐就更稳”

 输出为 12 灯圆环整环同色（颜色随强度渐变 + 亮度随强度变化）

对应代码见 [main.c:Music_Rhythm_Update](Core/Src/main.c#L785-L950)。

### 8.2 按键操作

 KEY1：退出回 Extended（并清灯、重置音乐校准状态）

 KEY2：退出回 Extended（并清灯、重置音乐校准状态）

### 8.3 蓝牙操作

`0`：退出回 Extended（并清灯、重置音乐校准状态）


## 八. Auto Bright（自动调光）

### 1. 功能说明

 通过光敏 ADC 值计算 LED 亮度，实现线性“亮度随光照变化”

 自适应学习 light_min/light_max：用于适配不同光敏模块方向/量程，并让差异更明显
 
 LCD 显示当前光照值与进度条

对应代码见：
光敏采样见 [light.c](Core/Src/light.c#L1-L32)

自动调光策略与 UI 更新见 [main.c:Auto_Brightness_Update](Core/Src/main.c#L952-L1019)

### 2. 按键操作

 KEY1：退出回 Extended（并清灯）
 KEY2：退出回 Extended（并清灯）

### 3. 蓝牙操作

 `0`：退出回 Extended（并清灯）

# LED_TEST 项目功能说明文档

## 1. 项目概述
本项目基于 STM32F103C8T6 开发板，实现了 LED 灯带控制（WS2812）、LCD 显示、按键交互、声音感应、光线感应及蜂鸣器反馈等功能。

## 2. 硬件连接说明
- **LCD 显示屏**:
  - RST: PA0
  - DC: PA1
  - CS: PB8
  - BLK: PB9
  - SCLK: PA5 (软件SPI)
  - MOSI: PA7 (软件SPI)
- **WS2812 灯带**:
  - 数据引脚: PB13 (TIM1_CH1N)
- **声音传感器**:
  - 模拟输出: PA6 (ADC1_IN6)
- **光敏传感器**:
  - 数字输入: PB0 (GPIO_Input, 上拉输入)
- **按键**:
  - KEY1: PB6 (外部中断，下降沿触发)
  - KEY2: PB7 (外部中断，下降沿触发)
- **蜂鸣器**:
  - 控制引脚: PB12
- **语言识别状态 LED**:
  - 引脚: PA4 (当前初始化为高电平，LED 熄灭)

## 3. 功能模块说明

### 3.1 LCD 显示与交互
- **UI 设计**: 采用简约美观的黑底白字风格，搭配青色（CYAN）高亮显示当前选中项，界面结构清晰。
- **启动界面**: 显示主菜单，可在“亮度调节”与“扩展功能”之间选择。
- **亮度调节模式**: 
  - 显示当前亮度等级 (1-10)。
  - KEY1 增加亮度，KEY2 减少亮度。
  - 灯带同步调节亮度。
- **扩展功能菜单**: 
  - **按键逻辑**: KEY1 循环切换选中模式（Color Mode / Music Mode / Auto Bright），KEY2 确认并进入选中的模式。
  - **Color Mode (颜色模式)**: KEY1 循环切换灯带颜色（红、绿、蓝、黄、紫、青、白）。
  - **Music Mode (音乐律动模式)**: 根据声音传感器采集的音频强度，实时调节灯带的亮度和颜色闪烁，并在 LCD 屏幕底部动态显示随声音强弱跳动的青色进度条。
  - **Auto Bright (自动调光模式)**: 依靠光敏电阻检测环境亮度，在明亮环境下自动提高灯带亮度，在昏暗环境下自动降低亮度。

### 3.2 按键驱动 (中断方式)
- 使用外部中断 (EXTI) 实现，响应迅速。
- 包含 200ms 软件消抖逻辑，防止误触发。
- 每次按键操作触发蜂鸣器短鸣 (50ms) 作为反馈。

### 3.3 WS2812 驱动库
- 基于 TIM1 PWM + DMA 方式驱动，不占用 CPU 资源。
- 兼容不同数量的 LED 灯（默认配置为 8 颗）。
- 提供 `WS2812_Set_Color`、`WS2812_Show`、`WS2812_Set_All` 等接口。

### 3.4 声音传感器库 (micphone)
- 基于 ADC 采样。
- 提供 `Micphone_GetAverage` 均值滤波函数，获取稳定的声音强度数据。

### 3.5 蜂鸣器库 (buzzer)
- 提供 `Buzzer_Beep_Short` 接口，实现非阻塞式的短鸣反馈。

### 3.6 光敏传感器库 (light)
- 基于 GPIO 数字输入检测环境光线强度。
- 提供 `Light_IsBright` 函数获取光照状态（明亮/昏暗），配合非阻塞式状态更新逻辑实现自动调光。

## 4. 代码结构
- `main.c`: 主逻辑控制、状态机跳转、自动调光、律动进度条逻辑及 UI 刷新。
- `lcd.c/h`: LCD 驱动。
- `ws2812.c/h`: 灯带驱动库。
- `micphone.c/h`: 声音传感器库。
- `light.c/h`: 光敏传感器驱动库。
- `buzzer.c/h`: 蜂鸣器库。
- `gpio.c`: 引脚初始化。

## 5. 注意事项
- 语言识别功能 (LD3320) 暂未集成，PA4 引脚目前固定为高电平。
- 音乐律动模式下的进度条灵敏度和阈值可根据实际环境在 `Music_Rhythm_Update` 函数中调整。
- 自动调光模式检测频率为 500ms 一次，以避免光线微小波动引起的频繁亮度切换。
